# CampusFlow

CampusFlow is a Flutter Web application designed to help college students
organize and manage their academic activities from a single dashboard.

## Features

- Academic dashboard
- Weekly timetable
- Assignment management
- Assignment search
- Attendance tracking
- Daily goals
- Student profile
- Local data persistence
- Dark/light mode
- Responsive design

## Technologies

- Flutter
- Dart
- Material 3
- Shared Preferences
- Git
- GitHub

## Platform

Flutter Web

## Deployment

The application can be deployed using GitHub Pages or Vercel.
